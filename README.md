# VALORANT Lore Bot

![version](https://img.shields.io/badge/version-1.3-blue) ![python](https://img.shields.io/badge/python-3.11+-green) ![aiogram](https://img.shields.io/badge/aiogram-3.31+-blueviolet)

Telegram-бот — справочник по агентам VALORANT: роли, способности, подробная статистика с графиками, описание и лор персонажей. Данные берутся из [valorant-api.com](https://valorant-api.com) и автоматически обновляются с выходом нового патча.

> Фанатский некоммерческий проект. Не связан с Riot Games и не одобрен ею. VALORANT и все связанные материалы — собственность Riot Games.

## Возможности

- 🎯 Навигация по агентам через меню и кнопки: роль → агент → карточка
- 👤 Карточка агента с портретом, ролью и описанием
- ⚡ Все способности агента (Q, E, C, ультимейт, пассивка) с подробными параметрами (цена, заряды, очки ульты, кулдауны, тайминги)
- 📊 Графики и статистика по персонажу и отдельным способностям *(в тестовом формате)*
- 📜 Лор всех 30 агентов в формате Rich Messages: таблица-досье, заголовки, списки
- 🎬 Гифка-презентация агента над текстом лора
- 🛠 Версия патча, на которой лежат данные
- 🔄 Автообновление: при старте бот сверяет версию игры и перезагружает данные, если вышел новый патч

> ⚠️ **Обратите внимание:** графики и статистика находятся в **тестовом формате** — их оформление, метрики и набор данных будут дорабатываться и меняться в будущих обновлениях.

## Стек

- Python 3.11+
- [aiogram 3.31+](https://docs.aiogram.dev/) — Telegram Bot API (нужен для Rich Messages)
- [matplotlib](https://matplotlib.org/) — генерация графиков статистики
- SQLite — хранение данных
- requests — запросы к valorant-api
- python-dotenv — загрузка токена из `.env`

## Структура проекта

```
├── main.py        # бот: меню, кнопки, обработчики
├── charts.py      # генерация графиков статистики агентов и способностей
├── sync.py        # загрузка агентов из API в базу
├── api.py         # запросы к valorant-api и очистка текста
├── db_helper.py   # работа с SQLite: схема, запись, чтение
├── lore/          # лор агентов: jett.txt + jett_present_video.mp4 и т.д.
├── statistics/    # JSON-файлы с числовыми параметрами способностей агентов
├── .env           # токен бота (не коммитится)
└── valo_bot.db    # база данных (создаётся автоматически)
```

## База данных

| Таблица | Что хранит |
|---|---|
| `agents` | uuid, имя, роль, описание, портрет, версия патча |
| `abilities` | способности агента: слот, название, описание |
| `lore` | записи лора агента и ссылка на источник |

`abilities` и `lore` связаны с `agents` через `agent_uuid`.

## Установка и запуск

1. Клонируй репозиторий и создай виртуальное окружение:
   ```bash
   git clone https://github.com/KISEL4KO/<repo>.git
   cd <repo>
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # Linux / macOS
   ```

2. Установи зависимости:
   ```bash
   pip install "aiogram>=3.31" requests python-dotenv matplotlib
   ```

3. Создай бота у [@BotFather](https://t.me/BotFather) и положи токен в файл `.env`:
   ```
   BOT_TOKEN=твой_токен
   ```

4. Запусти бота:
   ```bash
   python main.py
   ```
   При первом запуске база создастся и заполнится автоматически.

### Полезные команды

```bash
python sync.py   # принудительно перезагрузить агентов из API
python api.py    # проверить ответ API (версия игры и первый агент)
```

### Как добавить гифку агента

Положи ролик в `lore/` под именем `<имя>_present_video.mp4`. **В ролике не должно быть звуковой дорожки** — иначе Telegram покажет его как видео с плеером, а не как гифку. Убрать звук без потери качества (нужен [ffmpeg](https://ffmpeg.org)):

```bash
ffmpeg -i jett_raw.mp4 -c copy -an jett_present_video.mp4
```

## Как устроено обновление данных

1. `sync.py` запрашивает текущую версию игры (`/v1/version`).
2. Если она совпадает с версией в базе — ничего не делает.
3. Если вышел новый патч — скачивает всех агентов (`/v1/agents?isPlayableCharacter=true&language=ru-RU`), обновляет записи в `agents` и полностью перезаписывает их способности.
4. Игровая разметка в описаниях (`<whitebold>…</>`) превращается в жирный текст Telegram.

Лор (`lore/`) и числовые характеристики способностей (`statistics/`) не перезаписываются при обновлении и редактируются вручную.
