# VALORANT Lore Bot

Telegram-бот — справочник по агентам VALORANT: роли, способности, описание и лор персонажей. Данные берутся из [valorant-api.com](https://valorant-api.com) и автоматически обновляются с выходом нового патча.

> Фанатский некоммерческий проект. Не связан с Riot Games и не одобрен ею. VALORANT и все связанные материалы — собственность Riot Games.

## Возможности

- 🎯 Навигация по агентам через меню и кнопки: роль → агент → карточка
- 👤 Карточка агента с портретом, ролью и описанием
- ⚡ Все способности агента (Q, E, C, ультимейт, пассивка)
- 📜 Лор персонажей с указанием источника
- 🛠 Версия патча, на которой лежат данные
- 🔄 Автообновление: при старте бот сверяет версию игры и перезагружает данные, если вышел новый патч

## Стек

- Python 3.11+
- [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API
- SQLite — хранение данных
- requests — запросы к valorant-api
- python-dotenv — загрузка токена из `.env`

## Структура проекта

```
├── main.py        # бот: меню, кнопки, обработчики
├── sync.py        # загрузка агентов из API в базу
├── api.py         # запросы к valorant-api и очистка текста
├── db_helper.py   # работа с SQLite: схема, запись, чтение
├── .env           # токен бота (не коммитится)
└── valo_bot.db    # база данных (создаётся автоматически)
```

## База данных

| Таблица | Что хранит |
|---|---|
| `agents` | uuid, имя, роль, описание, портрет, версия патча |
| `abilities` | способности агента: слот, название, описание |
| `lore` | записи лора агента и ссылка на источник |

`abilities` и `lore` связаны с `agents` через `agent_uuid`.

## Установка и запуск

1. Клонируй репозиторий и создай виртуальное окружение:
   ```bash
   git clone https://github.com/KISEL4KO/<repo>.git
   cd <repo>
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # Linux / macOS
   ```

2. Установи зависимости:
   ```bash
   pip install aiogram requests python-dotenv
   ```

3. Создай бота у [@BotFather](https://t.me/BotFather) и положи токен в файл `.env`:
   ```
   BOT_TOKEN=твой_токен
   ```

4. Запусти бота:
   ```bash
   python main.py
   ```
   При первом запуске база создастся и заполнится автоматически.

### Полезные команды

```bash
python sync.py   # принудительно перезагрузить агентов из API
python api.py    # проверить ответ API (версия игры и первый агент)
```

## Как устроено обновление данных

1. `sync.py` запрашивает текущую версию игры (`/v1/version`).
2. Если она совпадает с версией в базе — ничего не делает.
3. Если вышел новый патч — скачивает всех агентов (`/v1/agents?isPlayableCharacter=true&language=ru-RU`), обновляет записи в `agents` и полностью перезаписывает их способности.
4. Игровая разметка в описаниях (`<whitebold>…</>`) превращается в жирный текст Telegram.

Лор не перезаписывается при обновлении — он добавляется отдельно через `add_lore()`.
